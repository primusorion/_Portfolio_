# G. Sai Pradhun Portfolio

Welcome to my personal portfolio website! 🌌  

I’m **G. Sai Pradhun**, a Future Edge AI Architect | Starry-Eyed Astronomer | Digital Dreamer. I build thinking machines by day and wander the cosmos (and code) by night. This portfolio showcases my projects, skills, and journey as a developer and space enthusiast.

---

## 🚀 Features

- **Hero Section** with cosmic background and profile image  
- **About Me** section with bio and skill cards  
- **Projects** section with interactive, responsive project cards  
- **Cosmic-themed animations** using Framer Motion and subtle starfield effects  
- Fully **responsive and modern UI** built with React and Tailwind CSS  

---

## 🛠️ Tech Stack

- **Frontend:** React, Tailwind CSS  
- **Animations:** Framer Motion, react-tsparticles (starfield)  
- **Backend / Projects:** Node.js, Python, AI/ML frameworks (TensorFlow, PyTorch)  
- **Version Control:** Git & GitHub

## ⚡ Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/sai-portfolio.git

# Navigate into the folder
cd sai-portfolio

# Install dependencies
npm install

# Start development server
npm start
```

## 🌌 Usage
Replace src/assets/profile.png with your own profile image

Replace src/assets/cosmos.png / about-bg.png with your desired backgrounds

Add your projects in Projects.js
